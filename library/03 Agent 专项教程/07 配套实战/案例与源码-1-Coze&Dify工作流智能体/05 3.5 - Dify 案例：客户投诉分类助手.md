# 3.5 - Dify 案例：客户投诉分类助手

---

## 本案例概要

### 使用的工具 / 节点

| 类型         | 名称 / 能力 | 作用                                                                 |
| ------------ | ----------- | -------------------------------------------------------------------- |
| **节点**     | 开始        | 接收用户反馈内容（如 `feedback`），作为工作流输入。                  |
| **节点**     | 问题分类器  | 调用 LLM，从预置问题列表中选出与用户提问最匹配的一级、二级分类。     |
| **节点**     | 总结助手    | 调用 LLM，根据一级/二级分类名称和用户问题生成简短总结。              |
| **内置工具** | 钉钉群消息  | 将总结等内容通过钉钉群机器人发送到指定群；需配置 Webhook、加签密钥。 |

### 技术要点

- **输入**：用户在「开始」节点填写反馈内容（`feedback`）。
- **两级分类**：问题分类器（可配置为两级）调用 LLM，从预置列表中选出最符合的一级分类与二级分类，输出 `class_name` 等供下游使用。
- **总结生成**：总结助手在系统提示词中注入上一级的一级/二级分类名和用户问题，要求 LLM 只输出总结内容；通过 `/` 或变量引用关联上游输出。
- **钉钉推送**：使用 Dify 内置的钉钉群机器人工具，在工具中填写 Webhook 的 `access_token` 与加签密钥；注意 ACCESS TOKEN 填的是 Webhook URL 里 **access_token** 参数的值。

### 工作流程概览


<details class="code-example"><summary>代码 示例（点击展开）</summary>

```
开始(feedback：用户反馈)
    ↓
问题分类器(两级) → 一级 class_name、二级 class_name
    ↓
总结助手(一级分类名, 二级分类名, feedback) → 总结文本
    ↓
钉钉群消息工具(总结等) → 发送到钉钉群
    ↓
结束
```

</details>

## 2、具体实现

### 2.1 开始

创建空白应用。

![客户投诉分类助手案例操作截图](<../../../_resources/4b76b31597747575.png>)

接着开始编辑工作流。

工作流从此处开始。我们在输入字段中添加自己指定的输入内容。

![客户投诉分类助手案例操作截图](<../../../_resources/f63116dff8c2ca8f.png>)

![客户投诉分类助手案例操作截图](<../../../_resources/7933f3f60e674b38.png>)

### 2.2 问题分类器

这里调用了两级问题分类器。问题分类器会调用 LLM，从问题列表中选择与用户提问最匹配的一条，并进入该条对应的分支。

![客户投诉分类助手案例操作截图](<../../../_resources/fa6dfafebf30d3ac.png>)

### 2.3 总结助手

是问题分类器的下游，在系统提示词中传入两级分类的名称以及初始问题，要求进行总结（需要输入变量时输入 **/** 即可唤起变量联想）。

![客户投诉分类助手案例操作截图](<../../../_resources/3501f94c8a286c79.png>)


<details class="code-example"><summary>代码 示例（点击展开）</summary>

```
你是一个总结助手，将下面的问题进行总结
一级分类：{{#1763188881440.class_name#}}，二级分类：{{#1763189022754.class_name#}}，用户问题：{{#1763188813397.feedback#}}
```

</details>

### 2.4 钉钉群消息工具

首先在 Dify 的工具中添加钉钉群机器人工具。

![客户投诉分类助手案例操作截图](<../../../_resources/227e912bc011fd14.png>)

需使用 PC 端钉钉创建群机器人。先在你担任管理员的组织内创建一个群，然后在该群中创建机器人。

![客户投诉分类助手案例操作截图](<../../../_resources/0354a9fc4a608a85.png>)

![客户投诉分类助手案例操作截图](<../../../_resources/343395e1c210bc1e.png>)

![客户投诉分类助手案例操作截图](<../../../_resources/69df0d9f6df6c12e.png>)

![客户投诉分类助手案例操作截图](<../../../_resources/24d37ff803475533.png>)

保存该加签密钥，后续配置时会用到。

![客户投诉分类助手案例操作截图](<../../../_resources/2ccf3bdbb67a2944.png>)


<details class="code-example"><summary>代码 示例（点击展开）</summary>

```
SEC_YOUR_DINGTALK_SIGNING_SECRET

https://oapi.dingtalk.com/robot/send?access_token=YOUR_ACCESS_TOKEN
```

</details>

保存该 Webhook，后续配置时会用到。

![客户投诉分类助手案例操作截图](<../../../_resources/06ffcdc393f7ec00.png>)

完成创建后，在钉钉机器人工具中的「ACCESS TOKEN」中填入 Webhook 里的 `access_token` 值，在「加签密钥」中填入刚才保存的加签密钥。

> **注意**：ACCESS TOKEN 一定要填写 Webhook 中的 **access_token** 的值。
>
> https://oapi.dingtalk.com/robot/send?access_token=**YOUR_ACCESS_TOKEN**

![客户投诉分类助手案例操作截图](<../../../_resources/0a3e9e752690838e.png>)
