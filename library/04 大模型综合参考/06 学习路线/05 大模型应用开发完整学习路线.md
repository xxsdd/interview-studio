# 大模型应用开发完整学习路线

这条路线面向已有编程基础、准备转向大模型应用开发或 AI 后端的开发者。建议按顺序完成六个阶段；如果已有相关经验，可从对应专题切入。

| 阶段 | 核心目标 | 推荐入口 | 完成标志 |
|---|---|---|---|
| 0. 全局认知 | 看懂岗位、术语与技术版图 | [开发者入门路线](<03%20%E5%BC%80%E5%8F%91%E8%80%85%E5%85%A5%E9%97%A8%E8%B7%AF%E7%BA%BF.md>) | 能解释应用开发、算法和传统后端的边界 |
| 1. 模型调用 | 把模型可靠地接进业务 | [应用开发路线](<02%20%E5%A4%A7%E6%A8%A1%E5%9E%8B%E5%BA%94%E7%94%A8%E5%BC%80%E5%8F%91%E8%B7%AF%E7%BA%BF.md>) | 完成流式、结构化、有成本统计的 AI 应用 |
| 2. RAG | 建立可评估的知识库系统 | [RAG 专题](<../07%20%E4%B8%93%E9%A2%98%E7%B4%A2%E5%BC%95/05%20RAG%20%E4%B8%93%E9%A2%98.md>) | 有混合检索、引用与离线评测集 |
| 3. Agent | 掌握工具、状态、规划和恢复 | [Agent 路线](<01%20Agent%20%E4%B8%93%E9%A1%B9%E8%B7%AF%E7%BA%BF.md>) | Agent 可追踪、可中断、可评估 |
| 4. 生产工程 | 补齐部署、性能和可靠性 | [部署专题](<../07%20%E4%B8%93%E9%A2%98%E7%B4%A2%E5%BC%95/03%20%E9%83%A8%E7%BD%B2%E4%B8%8E%E6%80%A7%E8%83%BD%E4%B8%93%E9%A2%98.md>) | 有压测、容量和故障处理方案 |
| 5. 原理与面试 | 理解 Transformer，形成面试表达 | [面试路线](<04%20%E5%A4%A7%E6%A8%A1%E5%9E%8B%E6%B1%82%E8%81%8C%E4%B8%8E%E9%9D%A2%E8%AF%95%E8%B7%AF%E7%BA%BF.md>) | 能讲清原理、项目取舍与指标 |

## 推荐实战顺序

1. 最小 AI 应用：流式输出、结构化返回、错误处理、Token 成本统计。
2. 知识库问答：文档切片、混合检索、Rerank、引用、评测与错误分析。
3. 工具型 Agent：权限边界、Checkpoint、Trace、失败恢复与评测集。
4. 生产化改造：网关、限流、超时、重试、监控、灰度与容量报告。

需要按主题深入学习，可以前往[专题索引](<../07%20%E4%B8%93%E9%A2%98%E7%B4%A2%E5%BC%95/06%20%E4%B8%93%E9%A2%98%E7%B4%A2%E5%BC%95.md>)；需要查找全部资料，请使用[全量索引](<../00%20%E7%9B%AE%E5%BD%95.md>)。
