# 答练 · Interview Studio

在本机运行的中英文 AI 面试与教材练习工具。从一篇文章开始练习，用自己的话回答，再通过双语整理、具体反馈和讨论理解知识。

## 能做什么

- **按计划练习**：三周学习计划按周、天和完整文章选择，显示考点覆盖与通过进度。
- **双语回答与反馈**：忠实整理中文和英文，分别展示答对的地方、遗漏与错误、完整正确参考回答及表达建议。
- **继续提问**：对没理解的反馈继续追问，讨论保存在对应题目下，不增加答题次数或改变考点进度。
- **自己决定何时复盘**：三题后选择继续或复盘；三题不代表整篇已掌握。
- **独立练习记录页**：搜索、筛选、查看、继续、导出，删除后可从“最近删除”恢复。
- **文字与语音**：可选本地 Whisper 转写；微软语音只朗读面试官的问题，支持中英文、音色、倍速与本地缓存。
- **选择 AI**：本机 Codex 的 ChatGPT 订阅连接，或智谱、DeepSeek、自定义兼容 API；订阅模式可选模型及其支持的思考强度。
- **可见的处理状态**：进度、输入/输出 Token 用量、停止生成、失败后的本地恢复或手动重试。

## Windows 启动

需要 Python 3.12+。在仓库根目录用 PowerShell 执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item runtime.example.json runtime.json
```

编辑 `runtime.json`：将 `python` 改成这份仓库内 `.venv/Scripts/python.exe` 的完整路径。只有使用语音输入时才需要将 `model_path` 指向已下载的 faster-whisper 模型目录；没有模型时可以先用文字练习。

```powershell
.\.venv\Scripts\python.exe start.py
```

浏览器地址：<http://127.0.0.1:8766/>。进入“AI 连接设置”，配置所选服务后开始练习。

ChatGPT 订阅连接需要本机 Codex 已安装并使用 ChatGPT 登录，且能找到其 app-server 可执行文件。实现依赖当前本机 Codex 接口，其他版本或安装方式可能需要适配；订阅额度不足会停止，不自动切换收费 API 或购买额度。选择模型以实际检测结果为准。

语音转写默认使用 GPU；没有相应环境时，在设置中选择 CPU。微软语音需自行配置 Speech 资源、区域和密钥。程序提供本地字符用量保护，不会替 Azure 账户保证零账单。

## 数据与边界

- 网站只监听本机。练习、进度、讨论、设置和音频缓存保存在 `data/`；未提交草稿保存在当前浏览器。
- AI 生成仍需要联网：本题、相关教材、回答或讨论会发送给所选模型。本机存储不等于离线推理。
- API 密钥使用 Windows 账户加密保存。`data/`、密钥、本机 `runtime.json`、模型文件和日志均不入库。
- 新反馈使用“正确回答”；历史反馈保留原内容，不会自动重新生成或冒充新版参考答案。
- AI 的解释和判断可能出错，可结合教材来源核对。

## 项目结构

`app.py` 提供本机接口；`study.py` 管理教材练习与进度；`answer_contract.py` 约束忠实整理和反馈；`clarification.py` 处理反馈讨论；`static/` 是界面；`bank/`、`library/` 是个人学习用的教材快照。

本仓库作为个人私有源码备份。教材保留原有来源信息，部分本机导航链接在其他电脑上不可用；教材与角色图标不因收录在此而获得再分发授权。本仓库未声明开源许可证。
